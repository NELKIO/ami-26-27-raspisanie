# Расписание 1 курса · ВШЭ · 2026/27

Два одностраничных расписания, которые читают общие Google-таблицы факультетов
при каждом открытии. Изменения внутри подключённой книги подхватываются автоматически;
если факультет переносит расписание в другую книгу, адрес источника нужно заменить.

| Факультет | Адрес | Закреплены первыми | Источник |
|---|---|---|---|
| **ПМИ** (ФКН), по модулям | https://nelkio.github.io/ami-26-27-raspisanie/ | 2611-1 | таблица «Расписание ПМИ и ЭАД», вкладки «1 курс ПМИ N модуль» |
| **Математика**, по модулям + дополнительные курсы 1 семестра | https://nelkio.github.io/ami-26-27-raspisanie/math/ | БСБВЦ262, БМТМТ261 | [новая книга матфака](https://docs.google.com/spreadsheets/d/1LTYw2ORnM8EXkvIrWDpIjXCgWiXKquxYnyUJglVYIIs/edit): «1бак» (2 модуль) и «RS and SpecialCourses/НИСы и СК» |

Страницы независимы: свой адрес, свои данные, свой кэш. Друг на друга ссылаются в подвале.

Шуточная версия: https://nelkio.github.io/ami-26-27-raspisanie/fun/

## Общее для обеих

- **Только текущий модуль.** У каждого модуля своя вкладка таблицы, и каждый день берёт пары
  из вкладки своего модуля. Прошедшие модули с сайта убраны: сейчас показывается 2 модуль
  (с 01.11), даже если сегодня ещё октябрь, — отсчёт дат по умолчанию сдвигается на 02.11,
  а раньше 01.11 дату не выбрать. Граница задаётся `FIRST_MODULE` в начале скрипта и дальше
  сдвигается сама: в 3 модуле перестанет показываться 2-й. Переключатель модулей и строка
  «что поменялось» появляются, только когда модулей на сайте больше одного, — пока модуль
  один, его номер виден в шапке дня («2 мод. · 1 нед.»).
- **Календарь ВШЭ главнее таблицы.** Границы модулей, праздники (04.11, 23.02, 08.03,
  01.05, 09.05, 12.06), каникулы и недели сессии взяты из листа «график уч проц» в таблице
  матфака. В праздник и на каникулах пар нет — день помечен, карточки скрыты. На неделе
  сессии пары «С 03.11» без даты окончания больше не обещаются зелёным.
- **Новые вкладки модулей в подключённой книге подхватятся сами.** Они ищутся по названию
  и заголовку листа. Если кандидатов несколько, сначала используется известный `gid`,
  иначе — число дат внутри модуля. Пока вкладки следующего модуля нет, страница
  честно пишет об этом: внутри семестра показывает сетку прошлого модуля с предупреждением,
  через границу семестра — не показывает ничего.
- **Все группы.** Список групп и подписи читаются из таблицы, а не вшиты в код.
  Закреплённые стоят первыми и отделены чертой.
- **Реальные даты.** У дня недели показана ближайшая дата не раньше «отсчёта»:
  если сегодня вторник 01.09, то ЧТ — 03.09, а ПН — уже 07.09. Отсчёт можно
  переставить селектором даты справа от дней недели.
- **Цвет по датам.** <span style="color:#3fc39b">Зелёное</span> — пара в этот день идёт,
  <span style="color:#f2646a">красное</span> — нет. Пометки, по которым судить не о чем,
  остаются серыми.
- **Фильтр «только в этот день».** Прячет пары, которых в выбранную дату не будет;
  в шапке дня видно, сколько скрыто. Пары без указаний в таблице остаются:
  пропустить пару хуже, чем увидеть лишнюю.
- **Вся неделя.** Таблица, дни по горизонтали; колонка времени закреплена при прокрутке.
- **Тёмная и светлая тема.** Кнопка в подвале, выбор запоминается в браузере.
- **Личные настройки.** Последняя группа и кнопка «только в этот день» сохраняются
  отдельно для каждой страницы. На матфаке также сохраняются английский и выбранные
  НИСы/спецкурсы. Отсчёт дат при новом открытии начинается от сегодня.
- **Работает без обновления из Google.** Нет связи с таблицей — покажет последнюю
  загруженную копию из той же книги, нет и её — встроенный снимок: ПМИ от 30.10.2026,
  матфак (2 модуль и каталог дополнительных курсов) от 03.11.2026. Это резерв данных внутри страницы,
  а не установка офлайн-приложения: сама страница должна открыться из сети или кэша браузера.

## Особенности ПМИ

- Сетка ФКН: 9:30–21:00, семь пар. Подгруппы `261-1 … 2615-2`, 30 штук.
- Вкладки модулей: «1 курс ПМИ N модуль 26/27». Вкладку 1 модуля страница больше не читает.
  Вкладок «1 курс ПМИ 2 модуль» в книге две; живая — `gid=306794293` (даты с 02.11),
  вторая — старая копия 1 модуля с сентябрьскими датами, её страница не берёт.
- Служебные коды РУЗ вроде `26_27_М_ИР_Г_1111975_29` превращаются в «группа _29»
  у семинаров и убираются у лекций. «07.11 онлайн» — разовая онлайн-пара: только в эту дату.
- Даты в таблице пишутся явно: `С 10.09`, `30.09, 14.10`, `Отмена 04.09` — по ним и красится.
- Онлайн-пары помечены бейджем `ОНЛАЙН`, гибридные — «очно + трансляция»;
  ссылка на трансляцию берётся из ячейки (и из текста, и из гиперссылки).
- Английский в общей таблице не стоит: его ставят по языковым группам отдельно. Поэтому под
  расписанием есть карточка **«Мой английский»** — кнопка открывает панель с шестью вкладками
  по дням и семью слотами сетки ФКН; отмеченные слоты появляются в вашем расписании как пары
  «Английский язык» с пометкой «мой слот». Если слот занят парой группы, панель это показывает,
  а карточка подписывается «совпадает с: …». Если таблица сама ставит группе окно под
  английский (сейчас у 261-1, 264-2, 268-1/2), в панели у этого слота стоит пометка.
  Слоты свои у каждого модуля: пока во 2 модуле ничего не отмечено, берутся слоты, отмеченные
  ещё в 1 модуле, с пометкой «перенесены»; первое же изменение сохраняется отдельно для 2 модуля.
  Выбор хранится в этом браузере и не зависит от выбранной подгруппы.

## Особенности матфака

- Сетка матфака: 10:00–19:30, шесть пар, читается из таблицы (некоторые пары начинаются
  раньше, «с 9:30» — это стоит в пометке карточки).
- Группы `БМТМТ261–265` (БАКМАТ) и `БСБВЦ261–262` (СОВБАК), 7 штук. В конце октября
  факультет переименовал `БМТМТБ26x` в `БМТМТ26x` — сохранённый выбор группы переносится сам.
- **2 модуль из новой книги факультета**: лист «1бак», `gid=883693860`. Номер модуля
  берётся из заголовка «Расписание занятий на 2 модуль…», а не из `gid`: после копирования
  книги идентификатор листа остался прежним. Сетка 1 модуля больше не используется даже
  в резервном снимке. В проверенной выгрузке от 03.11 — 168 записей занятий на 7 групп
  (с учётом английского, вариантов по чётности и разовых занятий, не число пар за неделю).
- **Чётные и нечётные недели** вместо дат — по графику ВШЭ: в каждом модуле недели
  нумеруются заново, 1-я, 3-я… — нечётные. В 1 модуле неделя с 07.09 — чётная (2-я),
  во 2 модуле неделя с 02.11 — снова нечётная (1-я). В шапке дня: «2 мод. · 1 нед. · нечёт».
  У пары с пометкой `чёт`/`нечёт` метка зелёная, если на дате дня она идёт,
  красная и карточка приглушена — если нет.
- Аудитория показывается плашкой в карточке — в этой таблице она есть почти у каждой пары.
- Ссылки из ячеек показываются кнопкой в карточке: диск — «материалы», МТС Линк/Zoom —
  «подключиться». Голый URL из текста ячейки тоже подхватывается. Строка вида «Пароль для
  входа…: 1111» становится пометкой «пароль 1111» к паре, а пояснения перед «Л:»/«С:»
  («17.10 пройдёт три пары Л: …») — пометкой, а не частью названия.
- **Разовые даты** (`21.11 и 28.11`, `даты: …`) и варианты `чет`/`чёт`, `нечет`/`нечёт`
  разбираются одинаково. Контрольная работа отдельным абзацем — отдельная карточка,
  а не примечание к предыдущей паре. Пометка «вместо 4.11» без новой даты сохраняется
  с предупреждением об уточнении: дата переноса не угадывается, зелёного обещания нет.
- **Английский** стоит прямо в сетке группы с уровнем (базовый / основной / продвинутый),
  преподавателем и аудиторией. Явная пометка «в 110 ауд.» важнее старого номера ниже;
  дата начала берётся только из текста, не добавляется автоматически. По умолчанию скрыт —
  кнопка «английский» рядом с датой.
- Типы занятий: лекция, семинар, НИС (научно-исследовательский семинар), английский,
  прочее (БЖД).
- Пометки «только для БАКМАТ», «БАКМАТ+СОВБАК», «с октября» переносятся в карточку как есть.

## НИСы и спецкурсы на матфаке

Кнопка **«Выбрать курсы»** открывает каталог с поиском по названию и преподавателю.
Курсы сгруппированы по курсу обучения, с которого они доступны («С 1 курса», «С 2 курса»
и так далее; курсы без такой пометки в таблице — в конце). На компьютере — две колонки
карточек, на телефоне — полноэкранный список с закреплённой кнопкой «Готово».
Можно показать только выбранные курсы или снять все отметки.

По умолчанию **ничего не выбрано**. При этом в расписании остаются **обязательные НИСы
самой группы** — они приходят из листа «1бак», а не из каталога по выбору.
Например, у НИСа «Тривиум. Математика» во 2 модуле указаны даты 14.11, 28.11, 12.12 и 26.12
и начало в 11:00. Фильтр «только в этот день» учитывает этот список, а не старую чётность.
Занятия из каталога, в отличие от обязательных, помечены **«по выбору»**.

- Источник — [лист «RS and SpecialCourses/НИСы и СК» новой книги](https://docs.google.com/spreadsheets/d/1LTYw2ORnM8EXkvIrWDpIjXCgWiXKquxYnyUJglVYIIs/edit?gid=1583908539).
  Каталог и основное расписание разбираются из одной ZIP-выгрузки. В снимке от 03.11 —
  19 курсов, включая один аннулированный: он виден в каталоге, но не добавляется в расписание.
- Выбранные курсы добавляются в день и неделю с пометкой **«по выбору»**. Их время
  не округляется до сетки основной группы. Объединение на две пары показывается
  одним занятием с полным интервалом и подписью «2 пары подряд».
- Учитываются начало занятий и период листа (сейчас 01.09–30.12.2026). Отменённый курс
  нельзя выбрать; если ранее выбранный курс отменят, он исчезнет из сетки с предупреждением.
  Неопределённая или подозрительная дата не исправляется догадкой: видна пометка об уточнении.
- Аудитории, преподаватели, рекомендуемый курс обучения и ссылки берутся из ячеек.
  При живой загрузке номер встречи Zoom и пароль, написанные текстом, сохраняются
  в примечании; пароль не принимается за номер аудитории. Исходные ссылки Zoom сохраняются
  целиком и показываются кнопкой «подключиться», в том числе во встроенном снимке.
  Если номер встречи и пароль указаны только текстом, в публичном снимке вместо них
  оставлена ссылка на исходный лист; при живой загрузке они отображаются полностью.
  «Курс аннулирован» учитывается так же, как «курс отменён».
  У времени, переопределённого в тексте, окончание по сетке отмечается отдельно.
  Совпадения по времени с другими видимыми занятиями подсвечиваются предупреждением.
- Например, **«Проективная алгебраическая геометрия 1»** (`1249874`): четверг,
  16:20–17:40, Артамкин И.В., аудитория 110 — по снимку от 03.11.2026.
- Выбор привязан к коду курса, а не к строке/времени: перестановка курса в таблице
  не сбрасывает отметку. Выбор общий для групп внутри страницы матфака.
- Это **личное отображение, не запись на курс**. Допуск и включение в ИУП уточняются
  у факультета. Кнопка «английский» скрывает языковые занятия, но не выбранные НИСы
  на английском языке.

## Где хранятся настройки

Используется `localStorage`, без аккаунтов и cookies. Настройки остаются в конкретном
браузере на конкретном устройстве и не передаются на GitHub, Google или другим посетителям.
Другой браузер, профиль или устройство получает собственный выбор. Люди, пользующиеся
одним профилем браузера, разделяют его настройки. Очистка данных сайта удаляет настройки;
синхронизации между телефоном и компьютером нет.

| Данные | Ключ localStorage |
|---|---|
| Группа, фильтр и слоты английского ПМИ (по модулям) | `raspis2_prefs_v1` |
| Группа, фильтры и выбранные курсы матфака | `raspis_math_prefs_v1` |
| Кэш расписания ПМИ / матфака по модулям | `raspis3` / `raspis_math_mods` |
| Кэш каталога НИСов и спецкурсов | `raspis_math_courses_v1` |
| Тема (общая для двух страниц) | `theme` |

Кэш матфака содержит идентификатор книги `source`. Кэш старой книги или запись без
этого идентификатора не заменяет новое расписание; вместо неё используется свежий
встроенный снимок. Группа, фильтры и выбранные курсы при смене источника сохраняются.

Если сохранение запрещено браузером или JSON настроек повреждён, страница продолжит
работать с настройками по умолчанию. Недоступность каталога курсов не блокирует обновление
основного расписания: для каталога остаётся отдельный кэш или встроенный снимок,
и это явно указано на странице.

## Как это устроено

Один файл на страницу (`index.html`, `math/index.html`), без сборки и зависимостей:
стили и скрипт внутри, снаружи грузятся только шрифты Google Fonts.

Источник данных — выгрузка книги в zip (`export?format=zip`). Это **единственный** формат,
в котором Google отдаёт объединения ячеек (`colspan`/`rowspan`) и гиперссылки. Это
принципиально: лекция потока лежит в таблице одной ячейкой, растянутой на несколько групп,
и без разворачивания объединений её нельзя разложить по группам. `csv` и `gviz` объединения
теряют, `htmlview` и `pubhtml` сейчас отдают пустую JS-оболочку без разметки.

Zip распаковывается прямо в браузере, без библиотек: центральный каталог zip плюс
`DecompressionStream("deflate-raw")`. Из книги выбираются HTML вкладок модулей — по названию
файла в zip (это название вкладки), gid виден в идентификаторах строк. Полумегабайтный
`sheet.css` не распаковывается. Календарь модулей, праздников и сессий — в начале скрипта
(`MODULES`, `HOLIDAYS`, `BREAKS`), его нужно обновить раз в учебный год.

## Почему сайт, а не файл

Google отдаёт заголовок `Access-Control-Allow-Origin` эхом того адреса, с которого пришёл
запрос — но только если адрес настоящий. У страницы, открытой двойным кликом (`file://`),
адрес отсутствует (`Origin: null`), и Google не отвечает **ни по одному** из своих адресов,
включая `gviz`. Поэтому живая загрузка возможна только с http(s): GitHub Pages, либо локально:

```bash
python3 -m http.server 8000
```

Третий путь, если очень нужен именно локальный файл, — развернуть веб-приложение
Apps Script (готовый код лежит в комментарии в начале `<script>`) и вписать его адрес
в `APPS_SCRIPT_URL`.

## Проверки

Регрессии парсера матфака, объединений, загрузки и миграции кэша запускаются в браузере:

```bash
python3 -m pip install playwright
python3 -m playwright install chromium  # не нужно, если установлен Google Chrome на macOS
python3 -I tests/test_math_browser.py
```

Тесты сами поднимают временный локальный сервер, используют примеры ячеек новой книги
и фиксированную дату 03.11.2026; доступа к Google им не требуется.

## Обновление

Расписание обновляется само. Если менялись сами страницы:

```bash
git add -A && git commit -m "правки" && git push
```

Через минуту GitHub Pages подхватит новую версию.
