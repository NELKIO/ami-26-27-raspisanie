# Расписание ПМИ, 1 курс · 1 семестр 26/27

Одностраничное расписание всех 30 подгрупп первого курса ПМИ (БПМИ261 … БПМИ2615).
Данные подтягиваются напрямую из общей таблицы «Расписание ПМИ и ЭАД, 1 семестр 26/27» —
править и обновлять здесь ничего не нужно, страница читает таблицу при каждом открытии.

**Открывать здесь → https://nelkio.github.io/ami-26-27-raspisanie/**

## Что умеет

- **Все подгруппы.** 2611-1 и 266-2 закреплены первыми, остальные — в порядке таблицы.
- **Дни и «вся неделя».** Открывается на сегодняшнем дне; во «всей неделе» колонка времени
  закреплена при горизонтальной прокрутке.
- **Реальные даты.** У каждого дня недели показана ближайшая дата не раньше «отсчёта»:
  если сегодня вторник 01.09, то ЧТ — это 03.09, а ПН — уже 07.09.
- **Цвет по датам.** Пометки вида `С 10.09`, `30.09, 14.10`, `05.09` сравниваются с датой дня:
  зелёное — пара в этот день идёт, красное — нет. В списке дат подсвечивается именно
  совпавшая. Пометки без дат («С 2 модуля», «В сентябре», номер аудитории) остаются серыми —
  по ним судить не о чем.
- **Селектор даты.** Справа от дней недели: можно отмотать отсчёт на любое число
  и посмотреть, что будет идти.
- **Фильтр «только в этот день».** Прячет пары, которых в выбранную дату не будет;
  в шапке дня видно, сколько скрыто. Пары, у которых в таблице вообще нет дат
  («С 2 модуля» и подобные — их 10 из 628), остаются видимыми: судить по ним не о чем,
  а пропустить пару хуже, чем увидеть лишнюю.
- **Онлайн и трансляции.** Полностью онлайновые пары помечены бейджем `ОНЛАЙН`, гибридные —
  «очно + трансляция»; ссылка на трансляцию берётся из таблицы (и из текста, и из гиперссылки).
- **Работает офлайн.** Нет сети — покажет последнюю загруженную копию из localStorage,
  нет и её — встроенный снимок таблицы.

Английский язык в расписание не входит: он ставится по языковым группам отдельно.
Аудитории и переносы — в [РУЗ](https://ruz.hse.ru/).

## Как это устроено

Один файл `index.html` без сборки и зависимостей: стили и скрипт внутри, снаружи грузятся
только шрифты Google Fonts.

Источник данных — выгрузка книги в zip (`export?format=zip`). Это **единственный** формат,
в котором Google отдаёт объединения ячеек (`colspan`) и гиперссылки. Это принципиально:
лекция потока лежит в таблице одной ячейкой, растянутой на 10–20 колонок, и без разворачивания
объединений её нельзя разложить по подгруппам. `csv` и `gviz` объединения теряют, `htmlview`
и `pubhtml` сейчас отдают пустую JS-оболочку без разметки.

Zip распаковывается прямо в браузере, без библиотек: центральный каталог zip плюс
`DecompressionStream("deflate-raw")`. Из книги берётся только HTML нужного листа
(он опознаётся по `gid` в идентификаторах строк), 500-килобайтный `sheet.css` не распаковывается.

Список подгрупп и их подписи (группа, номера в РУЗ) тоже читаются из таблицы, а не вшиты
в код: если в таблице появится новая подгруппа, она появится и здесь.

## Почему сайт, а не файл

Google отдаёт заголовок `Access-Control-Allow-Origin` эхом того адреса, с которого пришёл
запрос — но только если адрес настоящий. У страницы, открытой двойным кликом (`file://`),
адрес отсутствует (`Origin: null`), и Google не отвечает **ни по одному** из своих адресов,
включая `gviz`. Поэтому живая загрузка возможна только с http(s): GitHub Pages, либо локально:

```bash
python3 -m http.server 8000
```

Есть и третий путь, если очень нужен именно локальный файл, — развернуть веб-приложение
Apps Script (готовый код лежит в комментарии в начале `<script>`) и вписать его адрес
в `APPS_SCRIPT_URL`.

## Обновление страницы

Расписание обновляется само. Если менялся сам файл:

```bash
git add -A && git commit -m "правки" && git push
```

Через минуту GitHub Pages подхватит новую версию.
