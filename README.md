## Общее для обеих

- **Все группы.** Список групп и подписи читаются из таблицы, а не вшиты в код.
  Закреплённые стоят первыми и отделены чертой.
- **Реальные даты.** У дня недели показана ближайшая дата не раньше «отсчёта»:
  если сегодня вторник 01.09, то ЧТ — 03.09, а ПН — уже 07.09. Отсчёт можно
  переставить селектором даты справа от дней недели.
- **Цвет по датам.** <span style="color:#3fc39b">Зелёное</span> — пара в этот день идёт,
  <span style="color:#f2646a">красное</span> — нет. Пометки, по которым судить не о чем,
  остаются серыми.
- **Фильтр «только в этот день».** Прячет пары, которых в выбранную дату не будет;
  в шапке дня видно, сколько скрыто. Пары без указаний в таблице остаются:
  пропустить пару хуже, чем увидеть лишнюю.
- **Вся неделя.** Таблица, дни по горизонтали; колонка времени закреплена при прокрутке.
- **Тёмная и светлая тема.** Кнопка в подвале, выбор запоминается в браузере.
- **Личные настройки.** Последняя группа и кнопка «только в этот день» сохраняются
  отдельно для каждой страницы. На матфаке также сохраняются английский и выбранные
  НИСы/спецкурсы. Отсчёт дат при новом открытии начинается от сегодня.
- **Работает без обновления из Google.** Нет связи с таблицей — покажет последнюю
  загруженную копию, нет и её — встроенный снимок основного расписания от 01.09
  и каталога дополнительных курсов от 05.09.2026. Это резерв данных внутри страницы,
  а не установка офлайн-приложения: сама страница должна открыться из сети или кэша браузера.

## Особенности ПМИ

- Сетка ФКН: 9:30–21:00, семь пар. Подгруппы `261-1 … 2615-2`, 30 штук.
- Даты в таблице пишутся явно: `С 10.09`, `30.09, 14.10`, `Отмена 04.09` — по ним и красится.
- Онлайн-пары помечены бейджем `ОНЛАЙН`, гибридные — «очно + трансляция»;
  ссылка на трансляцию берётся из ячейки (и из текста, и из гиперссылки).
- Английский в расписание не входит: он ставится по языковым группам отдельно.

## Особенности матфака

- Сетка матфака: 10:00–19:30, шесть пар, читается из таблицы (некоторые пары начинаются
  раньше, «с 9:30» — это стоит в пометке карточки).
- Группы `БМТМТБ261–265` (БАКМАТ) и `БСБВЦ261–262` (СОВБАК), 7 штук.
- **Чётные и нечётные недели** вместо дат. Неделя с 07.09 — чётная, с 14.09 — нечётная;
  дальше чередуются. У пары с пометкой `чёт`/`нечёт`
  метка зелёная, если на дате дня она идёт, красная и карточка приглушена — если нет.
  Если факультет считает иначе, поменяйте `PARITY_EPOCH` в начале скрипта.
- Аудитория показывается плашкой в карточке — в этой таблице она есть почти у каждой пары.
- **Английский** стоит прямо в сетке группы с уровнем (базовый / основной / продвинутый),
  преподавателем и аудиторией, стартует с 21.09. По умолчанию скрыт — кнопка «английский»
  рядом с датой.
- Типы занятий: лекция, семинар, НИС (научно-исследовательский семинар), английский,
  прочее (БЖД).
- Пометки «только для БАКМАТ», «БАКМАТ+СОВБАК», «с октября» переносятся в карточку как есть.

## НИСы и спецкурсы на матфаке

Кнопка **«Выбрать курсы»** открывает каталог с поиском по названию и преподавателю.
Курсы сгруппированы по курсу обучения, с которого они доступны («С 1 курса», «С 2 курса»
и так далее; курсы без такой пометки в таблице — в конце). На компьютере — две колонки
карточек, на телефоне — полноэкранный список с закреплённой кнопкой «Готово».
Можно показать только выбранные курсы или снять все отметки.

По умолчанию **ничего не выбрано**. При этом в расписании остаются **обязательные НИСы
самой группы** — они приходят из листа «1 бак с 7.09», а не из каталога по выбору.
Например, НИС «Тривиум. Математика» по субботам стоит у групп в сетке и показывается
всегда. Отличить просто: занятия из каталога помечены **«по выбору»**.

- Источник — [лист «RS and SpecialCourses/НИСы и СК»](https://docs.google.com/spreadsheets/d/1_DxncTDb5oQDG55bnuLluEZSiV88ZRLyIqXFMC3weMY/edit?gid=1583908539).
  Каталог и основное расписание разбираются из одной ZIP-выгрузки.
- Выбранные курсы добавляются в день и неделю с пометкой **«по выбору»**. Их время
  не округляется до сетки основной группы. Объединение на две пары показывается
  одним занятием с полным интервалом и подписью «2 пары подряд».
- Учитываются начало занятий и период листа (сейчас 01.09–30.12.2026). Отменённый курс
  нельзя выбрать; если ранее выбранный курс отменят, он исчезнет из сетки с предупреждением.
  Неопределённая или подозрительная дата не исправляется догадкой: видна пометка об уточнении.
- Аудитории, преподаватели, рекомендуемый курс обучения и ссылки берутся из ячеек.
  У времени, переопределённого в тексте, окончание по сетке отмечается отдельно.
  Совпадения по времени с другими видимыми занятиями подсвечиваются предупреждением.
- Например, **«Проективная алгебраическая геометрия 1»** (`1249874`): четверг,
  16:20–17:40, с 24.09, Артамкин И.В., аудитория 110 — по снимку от 05.09.2026.
- Выбор привязан к коду курса, а не к строке/времени: перестановка курса в таблице
  не сбрасывает отметку. Выбор общий для групп внутри страницы матфака.
- Это **личное отображение, не запись на курс**. Допуск и включение в ИУП уточняются
  у факультета. Кнопка «английский» скрывает языковые занятия, но не выбранные НИСы
  на английском языке.

## Где хранятся настройки

Используется `localStorage`, без аккаунтов и cookies. Настройки остаются в конкретном
браузере на конкретном устройстве и не передаются на GitHub, Google или другим посетителям.
Другой браузер, профиль или устройство получает собственный выбор. Люди, пользующиеся
одним профилем браузера, разделяют его настройки. Очистка данных сайта удаляет настройки;
синхронизации между телефоном и компьютером нет.

| Данные | Ключ localStorage |
|---|---|
| Группа и фильтр ПМИ | `raspis2_prefs_v1` |
| Группа, фильтры и выбранные курсы матфака | `raspis_math_prefs_v1` |
| Кэш основного расписания ПМИ / матфака | `raspis2` / `raspis_math` |
| Кэш каталога НИСов и спецкурсов | `raspis_math_courses_v1` |
| Тема (общая для двух страниц) | `theme` |

Если сохранение запрещено браузером или JSON настроек повреждён, страница продолжит
работать с настройками по умолчанию. Недоступность каталога курсов не блокирует обновление
основного расписания: для каталога остаётся отдельный кэш или встроенный снимок,
и это явно указано на странице.

## Как это устроено

Один файл на страницу (`index.html`, `math/index.html`), без сборки и зависимостей:
стили и скрипт внутри, снаружи грузятся только шрифты Google Fonts.

Источник данных — выгрузка книги в zip (`export?format=zip`). Это **единственный** формат,
в котором Google отдаёт объединения ячеек (`colspan`/`rowspan`) и гиперссылки. Это
принципиально: лекция потока лежит в таблице одной ячейкой, растянутой на несколько групп,
и без разворачивания объединений её нельзя разложить по группам. `csv` и `gviz` объединения
теряют, `htmlview` и `pubhtml` сейчас отдают пустую JS-оболочку без разметки.

Zip распаковывается прямо в браузере, без библиотек: центральный каталог zip плюс
`DecompressionStream("deflate-raw")`. Из книги выбирается HTML нужного листа
(на матфаке — двух листов), опознаваемого по `gid` в идентификаторах строк.
Полумегабайтный `sheet.css` не распаковывается.

## Почему сайт, а не файл

Google отдаёт заголовок `Access-Control-Allow-Origin` эхом того адреса, с которого пришёл
запрос — но только если адрес настоящий. У страницы, открытой двойным кликом (`file://`),
адрес отсутствует (`Origin: null`), и Google не отвечает **ни по одному** из своих адресов,
включая `gviz`. Поэтому живая загрузка возможна только с http(s): GitHub Pages, либо локально:

```bash
python3 -m http.server 8000
```

Третий путь, если очень нужен именно локальный файл, — развернуть веб-приложение
Apps Script (готовый код лежит в комментарии в начале `<script>`) и вписать его адрес
в `APPS_SCRIPT_URL`.

Расписание обновляется само. Если менялись сами страницы:

```bash
git add -A && git commit -m "правки" && git push
```
